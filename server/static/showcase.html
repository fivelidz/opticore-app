OptiCore — PMS

A modern, secure practice management system built in Rust for an Australian optometry clinic. Patient records, calendar, billing, clinical notes, and analytics — in one fast desktop app.

🦀 Rust backend 🖥️ Tauri desktop ⚛️ React UI 🔒 Healthcare-grade auth

What it does — the full clinic in one app

📅

Interactive Calendar

Month/Week/Day views, drag-to-create, drag-to-reschedule, mass-block time ranges, side panel with patient details, payment status on every slot.

👥

Patient Records

Deep patient files: demographics, allergies, OSDI scores, IPL treatments, clinical notes, appointment history, invoices — all on one scrollable page.

💳

Billing & Checkout

Two-column checkout with live invoice calculation, GST, discounts, multiple payment methods, auto-recorded payments.

📊

Analytics

Revenue over time, appointment volume, website traffic by source, conversion rates, KPI dashboards with real charts.

📬

Unified Messages

Email, WhatsApp, and website messages in one inbox — read, archive, link to patients.

📥

Patient Intake

Public details-entry page (no login) → submissions appear in the app for one-click import as patients.

🧑‍⚕️

User Management

Staff accounts with roles (admin, doctor, nurse, receptionist, read-only), create/edit/disable users.

🌙

Dark Mode

Full dark/light theme toggle, persisted. Clean, modern, fast.

Architecture — designed for multi-clinic, multi-PC

Cloudflare (edge) ─ Worker (public booking gateway) + D1 (queue) + Pages (website) │ HTTPS · shared secret + signed JWT Clinic LAN ──────────── one always-on Rust server (Windows Service) holds the authoritative SQLite DB │ LAN HTTP/HTTPS ┌────┴────┬─────────┬──────────┐ Tauri apps Reception Exam rm Ashley's PC ← all share one DB via the server

Security & data integrity

🔐

Argon2 + JWT, always on

Every patient-data route requires a valid JWT. No "disabled for demo" backdoors.

🛡️

Compile-time SQL

sqlx checks every query at compile time — the async bugs that broke the original can't happen here.

💾

5-layer backups

WAL → hourly snapshot → LAN replica → encrypted offsite → edge replay. No single point of failure.
